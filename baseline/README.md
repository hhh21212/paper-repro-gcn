# baseline · AI 生成的参考实现（只读）

## 这是什么

2026-11-02 之前，本仓库的 `src/`、`experiments/`、`results/` 由一个 AI 逐步写成并跑出结果（Cora 81.48% ± 0.72%）。
**陈亦州本人没有参与这些代码的编写、调试和运行**，因此它们不构成本人的复现成果。

为了两件事保留：

1. **诚实记录**：仓库历史里说清楚「哪些是 AI 写的、哪些是我写的」，而不是把 AI 的产出当自己的。
2. **对照参考**：我按论文从零重写时，可以拿它做数值对照和差异排查——但**不允许复制进 `src/`**。

## 文件

| 文件 | 内容 |
|------|------|
| `src/data.py` | Cora 加载 + 对称归一化（对应论文公式 2–4） |
| `src/gcn.py` | `GraphConvolutionLayer` + 两层 GCN（对应公式 8） |
| `experiments/train_cora.py` | 训练脚本，支持 `--runs N` |
| `results/cora-baseline.md` | 20 次随机初始化的均值±标准差与差异记录 |

## 使用规则

- **读**：可以，但要能逐行解释每一句在干什么，解释不了就先别读。
- **跑**：可以，作为「目标数值」的参照。
- **抄**：不行。抄进 `src/` 等于自欺，而且复试问一句就露馅。
