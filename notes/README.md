**Q2 · 关键近似**
论文用 Chebyshev 多项式把 $g_\theta(\Lambda)$ 截到 $K$ 阶，再取 $K=1$。这一步换来了什么？
（参数量从多少变多少、计算图变多长、感受野多大）为什么 $K=1$ 就叫「局部」？

**Q3 · renormalization trick**
一阶近似直接给出 $I_N + D^{-1/2} A D^{-1/2}$。论文改写成 $\tilde A = A + I_N$、$\tilde D_{ii}=\sum_j \tilde A_{ij}$、
$\hat A = \tilde D^{-1/2}\tilde A\tilde D^{-1/2}$。为什么必须改写？
提示方向：特征值的范围、多层堆叠时 $\hat A$ 反复自乘会发生什么、数值稳定性。
